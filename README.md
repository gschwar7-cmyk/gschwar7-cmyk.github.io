# Gerald Schwarz — portfolio

A lightweight, responsive portfolio built with plain HTML, CSS, and JavaScript.

## GitHub Pages

The complete site is in [`docs/index.html`](docs/index.html). In the repository's
**Settings → Pages**, publish from the `main` branch and select the `/docs`
folder. If Pages is instead configured to publish from the repository root,
[`index.html`](index.html) forwards visitors to the same site.

## Local preview

Open `docs/index.html` in a browser, or serve the repository with any static
file server.
